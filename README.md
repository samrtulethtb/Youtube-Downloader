# Youtube-Downloader

A small downloader project for working with YouTube, TikTok and Instagram media links, built around yt-dlp and FastAPI.

## Hosted downloader

Looking for a browser-based downloader instead of self-hosting?

[NoBsDL](https://nobsdl.com/) handles supported public video and audio links from YouTube, TikTok, Instagram and other supported platforms.

NoBsDL is a separate project.
